AI agents require isolated execution environments to safely run untrusted, model-generated code. LangSmith Sandboxes provide hardware-virtualized microVMs that give agents persistent, stateful computing environments with filesystem, shell, and package manager access while protecting production infrastructure from security risks like supply chain attacks and kernel exploits. This approach allows agents to operate with genuine autonomy over dedicated computational resources within the LangSmith platform ecosystem.

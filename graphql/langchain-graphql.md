# LangChain GraphQL API

LangChain is a framework for building LLM applications. The LangSmith API (the hosted platform) covers trace management, feedback collection, dataset management, evaluation runs, prompt versioning, and annotation queues for LLM app observability.

**Endpoint:** No native GraphQL endpoint — conceptual schema derived from LangChain REST/gRPC API
**Documentation:** https://docs.langchain.com/langsmith

- Reference: https://api.smith.langchain.com/redoc
- Schema: https://github.com/api-evangelist/langchain
